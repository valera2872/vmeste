# «Вместе к цели» — web MVP

Первый вертикальный срез веб-переноса Android-прототипа.

Тестовая публикация: `https://valera2872.github.io/vmeste/`

## Уже работает

- публичная стартовая страница;
- гостевой личный кабинет без регистрации;
- создание важной цели с ориентиром на 90 дней;
- автоматическое создание ближайшего шага;
- дела и посильные варианты;
- отметка результата;
- обязательное предложение следующего шага после завершения;
- сохранение данных в `localStorage`;
- экспорт и импорт `vmeste-export-v1.json`;
- единая модель данных с заделом под челленджи, практики и поддержку.

## Локальный запуск

```bash
cd web
npm install
npm run dev
```

Затем открыть `http://localhost:3000`.

## Проверка

```bash
npm run typecheck
npm run build
```

## Ограничения текущего этапа

- нет регистрации и серверной синхронизации;
- данные хранятся только в браузере;
- нет PWA, расширения и Android-импорта;
- челленджи, практики и поддержка пока представлены только в модели данных;
- это проверка главного цикла, а не завершённый коммерческий продукт.
