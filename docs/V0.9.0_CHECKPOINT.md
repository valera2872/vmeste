## Что реализовано

Цифровой помощник встроен непосредственно в редактор действия при выборе поддержки `С цифровым помощником`.

Он предлагает:

1. первый физический шаг;
2. прозрачное разложение действия на три части;
3. минимальный вариант, который можно выполнить при недостатке сил или времени.

Каждую подсказку пользователь применяет отдельной явной кнопкой. Ничего не сохраняется автоматически: окончательное изменение действия происходит только после нажатия `Сохранить изменения`.

На карточке текущего шага в `Пути к цели` для действий с цифровой поддержкой добавлен прямой вход `Разобрать действие с помощником`.

## Ограничение текущей версии

Помощник работает локально на прозрачных правилах и не обращается к облачной языковой модели. Это первая проверяемая продуктовая версия механики, а не универсальный AI-консультант.

## Сохранённые решения

- сценарий `Трудно начать` не изменён;
- таймер не запускается без явной команды пользователя;
- экран `Что ещё сейчас занимает вашу голову?` не изменён;
- обычные дела по-прежнему отделены от главной цели;
- существующие пользовательские данные совместимы с обновлением.
